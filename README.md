# 🎨 Galeria de Artes

Uma plataforma para compartilhar e descobrir desenhos e artes digitais.
O projeto funciona como uma **galeria online **, onde artistas podem publicar suas artes, explorar trabalhos de outros artistas e criar uma comunidade criativa.

---

## ✨ Objetivo do Projeto

Este projeto foi desenvolvido para:

* armazenar e organizar **desenhos e artes digitais**
* permitir que **artistas compartilhem suas criações**
* criar uma **galeria visual moderna**
* praticar desenvolvimento **Full Stack**

---

## 🚀 Tecnologias Utilizadas

### Backend

* Java
* Spring Boot
* Spring Security
* JPA / Hibernate

### Frontend

* React
* Vite
* JavaScript

### Banco de Dados

* MySQL

---

## 👤 Tipos de Usuário

A plataforma possui diferentes tipos de usuários:

* **Usuário** → pode visualizar e interagir com artes
* **Artista** → pode publicar suas próprias artes
* **Administrador** → gerencia usuários e conteúdos

---

## 📌 Funcionalidades

✔ Cadastro e login de usuários
✔ Perfis de artistas
✔ Publicação de desenhos
✔ Galeria de artes estilo Pinterest
✔ Visualização de artes de outros artistas
✔ Sistema de autenticação
